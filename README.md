# Flash Player TV

پخش‌کننده‌ی فلش برای Android TV — تم دارک، کنترل کامل با ریموت (D-pad)

Created By Mohammad Shaerpour

## امکانات
- انتخاب فلش (حافظه‌ی USB) و نمایش حجم مصرفی / آزاد
- داشبورد: ویدیوها، موسیقی، عکس‌ها، همه فایل‌ها
- مرور فایل‌ها به سبک File Explorer: آیکن پوشه، بندانگشتی عکس و ویدیو، پنل جزئیات (نام، نوع، حجم، تاریخ شمسی)
- نمایش عکس تمام‌صفحه: راست/چپ = بعدی/قبلی، OK = اسلایدشو
- پخش ویدیو (ExoPlayer): OK پخش/توقف، چپ/راست = ۱۰ ثانیه (نگه‌داشتن = ۶۰ ثانیه)
- پخش موسیقی با کاور آلبوم و اکولایزر
- شناسایی خودکار اتصال و جدا شدن فلش

## ساخت APK
**روش ۱ – GitHub Actions:** پروژه را در یک مخزن GitHub بگذارید و push کنید؛ APK در بخش Artifacts ساخته می‌شود.

**روش ۲ – Android Studio:** پوشه را باز کنید (Ladybug یا جدیدتر) و Build > Build APK.

## نصب روی تلویزیون
APK را با فلش یا adb نصب کنید: `adb connect <TV-IP>` سپس `adb install app-debug.apk`

هنگام اولین اجرا مجوز دسترسی به حافظه را تأیید کنید.
